# SteganoCrypto

Графическая программа для Linux на C++17, Qt 6 Widgets и Qt Concurrent для скрытия и извлечения данных в 24-битных BMP без сжатия. Ввод — текст из поля, TXT или другой файл данных. Результат сохраняется в новый файл по указанному пути.

## Сборка на Linux

Для Debian или Ubuntu:

```bash
sudo apt install g++ cmake qt6-base-dev libssl-dev
cmake -S . -B build
cmake --build build
./build/steganocrypto
```

## Контрольный запуск

1. Задайте локальный пароль и подтвердите его. В следующий раз приложение попросит ввести этот пароль.
2. Во вкладке **Скрытие** выберите `files/demo.bmp` из проекта. Вместимость составляет 376 байт.
3. Выберите **Ввести текст** и напишите сообщение. Для проверки второго режима выберите **Загрузить файл** и укажите `files/message.txt`. Задайте путь нового BMP и нажмите **Скрыть и сохранить**.
4. Откройте вкладку **Извлечение**. Путь к только что сохранённому BMP уже подставлен. Укажите имя нового файла, например `recovered.txt`, и нажмите **Извлечь и сохранить**. При работе с `message.txt` должно быть извлечено 47 байт. Сравните результат с исходным через `cmp`.
5. Во вкладке **Каталог** нажмите **Создать каталог**, затем **Добавить**. Укажите номер и название, кнопками **Выбрать…** укажите `files/demo.bmp` и `files/message.txt` из проекта. При сохранении программа скопирует выбранные файлы в папку каталога. Выделите запись и нажмите **Открыть для скрытия**.

Программа открывает прежнюю папку данных `$XDG_DATA_HOME/NSTU/BMP-LSB`. Если `XDG_DATA_HOME` не задана, используется `~/.local/share/NSTU/BMP-LSB`. Сохранённый пароль и записи каталога доступны после переименования. Папка `files` внутри неё относится к каталогу заданий. Для прямого скрытия и извлечения можно выбрать файлы из любой доступной локальной папки.

## Большие изображения

BMP и данные читаются блоками по 64 КиБ. На расчёт вместимости достаточно прочитать заголовок, а для миниатюры программа выбирает отдельные пиксели. Сохранение и извлечение идут в фоновом потоке. Служебная метка STG1 и порядок записи совместимы с предыдущей версией.

Предел формата — 4 294 967 295 байт на BMP. Поддерживаются 24-битные несжатые изображения. Реальная вместимость зависит от числа цветовых каналов, а при сохранении нужна доступная папка со свободным местом под новый BMP. Программа сохраняет результат через временный файл в этой папке.

## Исходники

`src/gui/` содержит главное окно, диалог входа, каталог и поля выбора файлов. `src/core/` содержит обработку BMP, алгоритм LSB, пароль, бинарные записи и файловые операции. `docs/modules.pdf` — схема модулей, `docs/modules.dot` — её редактируемый исходник для Graphviz.
